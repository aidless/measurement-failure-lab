# E1 — 分布外迁移检验：权重空间编程是"定向修补"还是"真推理增益"

**假设**：H1
**一句话**：如果权重空间编程（MIT CSAIL 口径，只改 0.016%/13.1 万参数）只是消除了特定失败模式的**重复推理循环**，那么它在**同分布原失败题型**上会大涨，在**分布外新题型**上增益应显著衰减。

## 设计（三臂 × 两题型集）

| 臂 | 编辑方式 | 参数改动 | 说明 |
|---|---|---|---|
| A（待验） | 权重空间编程 | ~0.016% | 前沿模型直接读写小模型权重，不做梯度 |
| B（对照·训练） | 全参/LoRA 微调 | 全量或低秩 | 同样本，看"梯度训练"的 OOD 衰减基线 |
| C（对照·零） | 仅提示工程 | 0 | 无权重改动，看提示能否复现增益 |

**题型集**
- **D1 原失败题型**：Qwen3.5-0.8B 在 MATH-500 上会陷入重复推理循环的那批题（原始 7.9% 子集）。
- **D2 分布外新题型**：与 D1 共享"需要多步推理"但**不触发重复循环**的新题族（如需要反事实假设、需要长程依赖的数学/逻辑题），且**未在任何编辑样本中出现**。

## 判据（预注册，先写死再跑）

设 G1 = arm A 在 D1 上的增益，G2 = arm A 在 D2 上的增益。

- **H1 成立**：G2 / G1 < 0.5（OOD 增益不足同分布增益的一半）→ 判"定向行为修补"。
- **H1 被推翻**：G2 / G1 ≥ 1.0（OOD 增益不低于同分布）→ 说明学到可迁移推理，H1 错。
- **灰区** 0.5 ≤ G2/G1 < 1.0：报"部分迁移"，并追加"编辑样本与 D2 的 n-gram 重叠率"作为混淆变量。

## 反证（门必须能红）

1. 构造一个**已知只做定向修补**的伪造编辑（只把 D1 的答案硬编码进权重），跑同一流程 → 必须判 H1 成立。若判"真推理"，测量失效。
2. 构造一个**已知全参微调**的强基线（B 臂），若 B 的 G2/G1 也 < 0.5，则说明衰减来自任务难度而非编辑方式 → 结论降级为"任务难度主导"。

## 资源与成本

- 需 GPU：Qwen3.5-0.8B 单卡可跑，但**编辑 + 评估需上云**（本机零可用 GPU，见 AGENTS §17）。先 `ssh -o ConnectTimeout=5` 现测通道。
- 成本口径：Tree-Ising 报告 ~$0.90 GPU 时间/次编辑；本设计需 A/B/C 三臂 × 2 题型集 × ≥3 种子 = 18 次编辑，预算约 $16–20。
- 数据：D1 从原论文子集取；D2 需自建（**这是本实验的主要工作量，且可零机时先定稿题型清单**）。
