# 模型自我修改：权重空间编程与持续学习 — 证据基线（2026-11-19）

> 本文件记录方向立项时的**一手信息快照**，数字来自用户 2026-11 综述，尚未经本地复算；凡标「待验」的实验均为 proposed。

## 1. 权重空间编程（MIT CSAIL）

- 做法：前沿模型直接读写小模型权重，不做梯度训练。
- 声称：只改 0.016% 参数（13.1 万个），Qwen3.5-0.8B 的 MATH-500 7.9%→48.1%、GSM8K 13.8%→67.1%。
- 机制观察：主要消除**重复推理循环**，不是学会新推理链。
- 批评（必须计入）：更像「定向行为修补」；需要几十轮迭代评估；成本未摊销。
- 待验判据：分布外新题型（非原失败模式）上应无同等幅度增益。

## 2. Tree-Ising

- 做法：对 BF16 状态树做稀疏离散编辑（bit flips + GPU annealing）。
- 声称：约 $0.90 GPU 时间，可优于 158 轮前沿 agent 修复。
- 待验判据：对弥散性能力缺陷应失效；成本-效果曲线需按目标可定位性分层。

## 3. 持续学习

- Sandia AIGM Lite：增量学习准确率约 70%→90%+，缓解灾难性遗忘。
- 待验判据：换数据顺序/换任务切分后增益是否保持。

## 4. 递归自我改进与路线张力

- 有团队尝试 agent 自主诊断并修复预训练流水线（递归自我改进）。
- Richard Sutton：只靠暴力算力不够，需要新方法。
- Meta：tokenizer 并非必需，raw bytes 训练在规模上更优。
- 这两条不是同一维度的对立，需在跨 scale 配对消融中检验。
